# Nexwell 网站还原

## 当前方向

最终按用户确认回到原始参考图的整体构图，不采用中途的衬线字体与左右分栏探索。保留居中标题、森林首屏、胶囊弧线、三项原则、苔藓岛、树干后的四张半透明卡片、配方步骤和山谷页脚。

参考图按 1600px 宽桌面长页理解。桌面结构以原图为基线；窄屏、产品详情、文章及联系表单为交互延伸。主要素材是相近重构，不宣称逐像素一致。

## 素材与文字

按用户明确要求，瓶身文字直接生成在图片中，不用 HTML 或 SVG 另外贴标签。

- `forest-hero-labelled.webp`：首屏瓶子、森林、苔藓、接触阴影与光照为同一张完整场景。瓶子在左下三分之一，中心上方留出网页标题空间。
- `moss-product-island.webp`：带文字的瓶子与苔藓岛一体生成，不分别移动或叠加瓶体。
- `synbiotic-open-labelled.webp`：带完整产品标签的开口瓶，独立用于需要胶囊运动的配方章节。
- 胶囊与枝干沿用已有生成素材。当前页面使用五张生成素材，没有继续增加无关配图。

首屏标题、正文、按钮和步骤仍为真实 HTML，支持选择、点击和响应式布局。

## 视觉系统

- 主底色 `#edf0e9`，深绿 `#263c28`，墨色 `#20271f`。
- Manrope 用于标题和品牌字标，DM Sans 用于正文；Google Fonts CDN 与系统回退栈。
- 功能图标统一使用 Tabler Icons 轻描边 webfont。
- 保留源图的眉标、流程编号及卡片组织方式，只调整间距、对比度、焦点态和点击反馈。

## 入罐动画结构

胶囊、瓶口和瓶身使用同一个 `800 × 1000` SVG viewBox。分层顺序为：

1. 完整开口瓶背景。
2. 六颗独立运动的胶囊。
3. 用精确裁剪路径保留前侧瓶口和瓶身的同一张开口瓶图。

胶囊外层只负责位置，内部图层只负责旋转。终点位于瓶口内侧；下落后由真实瓶身前景遮住，不在瓶外提前淡出。原生 CSS sticky 保持桌面章节位置，ScrollTrigger 只驱动动画进度，不再直接修改固定章节的布局。紧凑视口不固定整章。

滚动范围基于未变形容器的真实文档坐标，在刷新与缩放时重算；物体运动坐标本身不依赖浏览器视口。统一时间轴支持连续滚动、倒放及重播。全局刷新只在必要的布局变化时执行，图片槽位已有固定比例，解码时不反复刷新。

减少动态效果时取消运动和章节停留，完整显示静态内容。动画 CDN 失败时仍保留原生交互。

## 交互与边界

- 产品 CTA 与热点打开产品详情；文章和承诺卡片展开对应内容。
- 生活方式轮播支持按钮、触控和边界反馈，按卡片实际宽度计算位置。
- 手机导航用事件路径判断外部点击，避免切换图标后菜单立刻关闭。
- 原生 dialog 管理模态语义和关闭；原入口隐藏时把焦点还给手机菜单按钮。
- 联系表单真实下载询问文本，不自动发送；订阅未接后台，明确显示不可用状态并保留输入。
- 不处理支付，不伪造业务成功，不缓存业务数据。
